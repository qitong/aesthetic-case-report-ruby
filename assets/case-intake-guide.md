# 医美病例汇报输入指南 (Case Intake Guide)

您可以直接发送原始病程记录、口述文字或门诊记录截图，无需严格按表格填写。如果您希望快速核对材料，可参考以下清单：

## 1. 必需材料 (Required)
- **患者病程与就诊旅程 (Patient Journey)**：
  - 患者代号/化名、年龄/性别、核心主诉（如泪沟凹陷、中面部松垂、下颏后缩等）、既往医美或手术史、求美期望。
  - 术前评估结论（如医生记录的分型 Innie/Outie、Hirmand 分级、FAS 面部评估得分或关键解剖问题）。
- **实际治疗记录 (Treatment Records)**：
  - 每次治疗的日期或相对时间节点（如首次治疗、术后 6 个月二次治疗）。
  - 各治疗靶区部位、患者左/右侧别（Left / Right / Midline）、注射层次（如骨膜上、DMCFP、眶隔前间隙、皮下等）、操作工具（锐针/钝针规格）、所用产品/设备及**实际剂量/参数（mL / U / 瓶数）**。
- **前后对比照片文件夹 (Photos Folder)**：
  - 照片所在文件夹路径（如 `./photos/`）。
  - 照片对应的时间节点（术前基线、术后即刻、1个月/3个月/6个月/跨年随访）与拍摄视角（正位、左/右 45° 斜位、左/右 90° 侧位、静态/微笑动态、术前画线布点图）。

## 2. 可选材料 (Optional)
- **参考学术论文 (Reference Paper)**：PDF 路径、DOI 或文献要点（用于构建“文献机制 + 临床病例结合型”汇报）。
- **模板与设计偏好**：
  - 使用内置 **Default 模板**（自动适配 `evidence-case` 文献结合型 或 `journey` 纵向抗衰旅程型）；
  - 或提供自定义 **`design.md`**（指定专属配色、字体、页数与版式）。
- **讲者与会议信息**：讲者姓名、机构/科室、会议名称、是否需要特定保密或合规页脚声明。
